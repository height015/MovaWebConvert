# Lagos marketing map

`lagos-urban-map.svg` is a locally hosted illustrative map asset generated for the Mova public website.

Cartographic structure:

- Lagos-area road geometry from the World Bank `Nigeria Roads` public dataset, licensed CC BY 4.0.
- Lagos-area road and waterway geometry distributed through the Humanitarian Data Exchange.
- OpenStreetMap-derived context is credited in the rendered map and linked to the ODbL notice.
- A subdued, non-navigational street texture is included for visual density. It does not represent live mobility, routing, or user-location data.

Sources:

- https://datacatalog.worldbank.org/search/dataset/0042080/nigeria-roads
- https://data.humdata.org/dataset/nigeria-roads
- https://data.humdata.org/dataset/nigeria-waterways
- https://www.openstreetmap.org/copyright
